One funny line pitching the worst pizza topping imaginable: a pizza topped with all the pizzas nobody bought — blended, re-baked, and served with a straight face. No pineapple, no anchovies, just the kitchen quietly recycling its own failures and calling it a special.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/wpt-test node main.ts
cat /tmp/wpt-test/entry.txt
```

The program writes a single line (under 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It is deterministic: no clock, no randomness, no network.
